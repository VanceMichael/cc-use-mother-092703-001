# 公益食品直播溯源与召回协同

贯通公益食品直播的资质、原料、订单、责任链和召回处置。

## 参与方与事实

主要参与方包括消费者、直播平台、主播与中间商、食品生产经营者、市场监管人员。领域资料记录以下已经确认的事实：

- 报道披露低价公益助农直播销售假冒核桃油
- 普通大豆油被灌装并贴上多个食用油品牌标签
- 抽检、线下溯源和平台责任需要打通全链条

## 业务约束

- 资质效力区间
- 原料和标签谱系
- 召回范围
- 责任隔离
- 佣金冲正
- 重复回执

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/food_context.py` 负责读取和校验这些资料。

## 开发命令

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

编译检查：

```bash
python3 -m compileall -q src
```

两条命令只读取仓库内文件，不需要连接外部业务系统。
